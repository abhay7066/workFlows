# Step 02 — Reel Script

## Input
- `01-strategy.md`: core message, format, recommended hook, platform, length, tone, CTA
- `../../brand-profile.md`: if filled in

## Task
Write a scene-by-scene script for a vertical (9:16) short video that follows the strategy exactly.

### Structure (default 30–40s reel, aim for 35s)
| Part | Time | Purpose |
|------|------|---------|
| Hook | 0–3s | Stop the scroll. Use the recommended hook. |
| Problem / setup | 3–10s | Make the viewer feel the pain or curiosity |
| Value / solution | 10–28s | Show the product solving it: show, don't tell |
| Payoff | 28–32s | The result or "aha" moment |
| CTA | 32–36s | One clear action |

Total length must be between 30 and 40 seconds unless the user asked for something else. That is usually 5–7 scenes.

### Writing rules
- **Spoken lines**: short and conversational. Aim for about 2.5 words per second (a 35s reel is roughly 80–95 spoken words, and 30–40s is 75–100).
- **One idea per scene.** Change the visual every 2–4 seconds to hold attention.
- **On-screen text** for every scene. Many people watch muted, so the video must make sense without sound.
- **No scene longer than 8 seconds.** Most AI video tools generate clips of about 8 seconds, so this keeps step 04 simple.
- Use placeholders for unknown facts, such as `[STAT]` or `[PRODUCT SCREEN: dashboard]`. Never invent them.
- Write a CTA that matches the goal in the strategy.

## Output
Write `02-script.md` in the run folder:

| 2 | 2–6s | ... | ... | ... |
